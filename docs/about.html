Built on Vexora.

Vexora Diagnostics adapts the Bluetooth device picker, name filters and Nordic UART service constant from Vexora by ignition, under the MIT license. Source revision: c8c1ea1043e69a9aac25c5e96bfcbd004a008b57, file public/assets/flasher.js. The interface and diagnostics workflow are new. The upstream repository's referenced logo, stylesheet and model images were absent, so this interface uses an original schematic illustration.

What this version does

Connects to a selected BLE device, enumerates browser-permitted services, reads selected readable characteristics, subscribes to selected notifications, and downloads JSON evidence. A notification subscription configures the device's notification descriptor.

It does not implement the upstream firmware updater or encrypted authentication session. Connecting successfully does not establish F3 compatibility or unlock telemetry. Hardware verification is pending.

Privacy

No analytics, account system, or device-data upload is included in this app. Device data lives in memory until this tab closes or reloads. The hosting platform may process ordinary access logs. Default reports omit names, browser device IDs, raw bytes and error messages. Raw-byte exports can contain identifying information; inspect them before publication.

Browser scope

Use HTTPS and Chrome on Android. The chooser includes common Vexora name prefixes, with a Show all devices option. This app initially requests Nordic UART, Ninebot UART, Device Information and Battery services. Other service UUIDs must be entered before reconnecting. Browser restrictions mean this is not a complete advertisement scanner.
