# Sources

Reviewed 2026-11-11. External claims have not been verified on the target scooter.

1. [BobMcGlobus/ha-ninebot](https://github.com/BobMcGlobus/ha-ninebot): project documentation reports Ninebot F3 support using Encryption2. A lead for protocol analysis, not evidence from our device. The project is AGPL-3.0; this repository currently links to it and contains no copied implementation.
2. [Nordic Semiconductor Android nRF Connect](https://github.com/nordicsemi/Android-nRF-Connect): official project, downloads, and feature documentation.
3. [nRF Connect documentation](https://github.com/nordicsemi/Android-nRF-Connect/blob/main/documentation/README.md): scanning, client operation, logging, and GATT server configuration.
4. [Nordic support: exporting cloned services](https://devzone.nordicsemi.com/f/nordic-q-a/67579/nrf-connect-android-app---where-does-it-export): describes selecting a cloned layout in Configure GATT Server and exporting XML. UI may differ by version.

When deriving future protocol details from source code, record the exact file and commit revision and preserve applicable attribution/license requirements.
